# Noisy workstation

Deterministic browser, Defender, Office, developer-tool, update, and background activity surrounds one injected PowerShell chain to test noise accounting at scale.

All identities and records are synthetic; there are no production credentials or organization-specific names in this scenario.

`raw_hits.ndjson` is generated on demand and intentionally not committed at scale. See `expected.yaml` for the machine-checked conclusions.
